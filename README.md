# Positron: Data Science Without Constraints

Opening keynote for [R Exchange 2026](https://r-exchange.com/). 20 minutes on why Positron exists -- removing the switches data science tools have made us accept.

**[View the slides](https://nstrayer.github.io/r-exchange-positron-why/)**

## Controls

- Arrow keys / Page Up/Down / swipe to navigate
- `N` -- speaker notes popup
- `F` -- fullscreen

## Run locally

```bash
npm install
npm run dev
```
